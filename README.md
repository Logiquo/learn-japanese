# 日语学习记录

最近开始学日语，所以把学习过程中觉得值得记录的东西整理在这里。

作为参考，我的背景是
1. 完全没有日语经验（很少看过日剧、日漫）。
2. 英语很好，所以外来语单词对我来说比较容易。
3. 每天只能有1小时时间学习日语。

## Anki 设定

Anki 是一个辅助记忆软件，可以在合适的时间提醒复习。
我按照我的使用习惯调整了下面的设定。
这里的设定是基于版本26.08.1的说明，后续版本设定或许会略有不同。

### Anki Web

建议注册一个 AnkiWeb 账号，可以很方便的同步不同设备之间的学习进度。

### 展示顺序

这个设定控制每天复习的卡片按照什么顺序展示，在`牌组选项`-`展示顺序`中调整，

- `新卡片抽取顺序`：这个一般取决于卡组是怎么设计的。
- `新卡片排列顺序`：使用默认设定`按抽取顺序`。
- `新学/复习的先后顺序`：选择`先复习，后学新`，这样可以确保学习时间不足的时候也能先巩固已经学会的内容，防止卡片堆积。
- `跨日卡片展示顺序`：使用默认设定`学新与复习混合`。
- `复习卡片排列顺序`：选择`按记忆可保留降序`，这样优先确保已经记得很好的卡片不会忘记，也防止所有的复习卡都记不住的无限复习地狱。

### FSRS

FSRS是一个比默认记忆算法更加先进的记忆算法，在`牌组选项`-`FSRS`中调整，

- 将`FSRS`打开
- 每隔一段时间应该点`优化当前预设`，这回使得FSRS算法根据近期的记录更加好的学习到记忆模式。

FSRS在初期的时候也许会经常预测错，但是随着使用和优化会越来越精准预测遗忘时间以便更好的排程。

### FSRS短期排程

这在当前版本中仍然是一个实验性功能，但是对于每天可以多次复习的人来说我认为是一个很有帮助的功能，因为大量的卡片的首次稳定期其实只有数小时，到第二天的时候会很容易完全忘记，导致复习的时候很痛苦。

#### Windows / MacOS / Linux

使用快捷键`Ctrl + Shift + ;`打开控制台，并执行下列指令
```Python
mw.col._set_enable_fsrs_short_term_with_steps(True)
print(mw.col.fsrs_short_term_with_steps_enabled)
```
如果现实`True`则说明启动成功。

#### Android / iOS

因为没有控制台选项，唯一的方法是在电脑设定好之后，使用AnkiWeb同步设定到 Android / iOS 系统。

### `重试`/`困难`/`良好`/`简单`

Anki默认在回答每个卡片之后会有四个选项，分别是`重试`/`困难`/`良好`/`简单`。但是其中`困难`/`良好`/`简单`主观判断很困难，而错误地使用又会很严重的导致FSRS计算错误。所以我强烈推荐只保留`重试`/`良好`两个选项。

#### Windows / MacOS / Linux

可以使用[AJT Flexible Grading](https://ankiweb.net/shared/info/1715096333)插件。在`工具`-`插件`-`获取插件`中，输入代码`1715096333`并点击`确定`即可安装插件。

安装插件后，在`AJT`-`Flexible Grading Options`中，将所有选项取消选择，只保留`Features`-`Pass fail`；并且将`Keys`中改成（Anki默认快捷键）`Again`: `1`，`Hard`: `2`，`Good`: `3`，`Easy`: `4`。

#### Android / iOS

可以在`设置`-`新学习屏`-`回答按钮`中启用`隐藏“困难”和“简单”按钮`。

## 五十音

学习日语的第一步当然是学习五十音，我首先观看了阿飞老师的视频对五十音有了一个基本的了解，然后使用Anki对五十音进行了背诵。

### 视频

视频使用Bilibili - 教日语的阿飞老师的日语入门，我感觉讲的很细致，声音听起来也很舒适，有听下去的欲望，

- [【日语入门】五十音（上）](https://www.bilibili.com/video/BV1Bp4y1D747/?p=3)
- [【日语入门】五十音（下）](https://www.bilibili.com/video/BV1Bp4y1D747/?p=4)
- [【日语入门】日语声调](https://www.bilibili.com/video/BV1Bp4y1D747/?p=5)
- [【日语入门】浊音和长音](https://www.bilibili.com/video/BV1Bp4y1D747/?p=6)
- [【日语入门】促音和拗音](https://www.bilibili.com/video/BV1Bp4y1D747/?p=7)
- [【日语入门】声调](https://www.bilibili.com/video/BV1Bp4y1D747/?p=8)

这些视频每个大约20-40分钟左右，我总计花费一周时间看完这些视频。

### 背诵

卡组在这里[kana/kana.apkg](kana/kana.apkg)。但是注意这个卡组使用的不是日语标准罗马字，而是IME罗马字输入，更加贴近平时日语输入法的拼写；而且JLPT并不考核罗马字，所以我就没打算学习Hepburn式或者训令式罗马字。

我的主要学习目标包括
- 看到平片假名，可以正确的发音；
- 看到平片假名，可以记住罗马字。

Anki的设定上，
- `新卡片抽取顺序`：选择`随机排列卡片`，因为这个卡组是按照五十音顺序排列的，如果不适用随机顺序，会可能出现仅仅记住五十音的顺序，而没有真正记住卡片的情况。

该卡组共214个卡片，我以每天20个新卡片的速度，大约3周时间将绝大部分卡片学习至`已熟练`。

## N5

我N5的学习策略是单词-语法-阅读-听力。主要的考量是
1. 没有足够单词积累，语法规则无法有效理解。
2. 在学会单词和语法，阅读和听力根本无法学习。
3. 听力比阅读更难一些，所以先学习阅读。

### 单词

单词这里强烈不建议新标日的单词表，一方面是因为有很多奇怪的专有名词，另一方面是单词量过高。这里我推荐[egg rolls JLPT卡组](https://github.com/5mdld/anki-jlpt-decks)，其中N5部分只有约800个单词。

我的主要学习目标包括
- 看到日语单词，可以知道中文意思；
- 看到日语单词，可以正确的发音；
- 看到含有汉字的单词，可以写出假名。

在 Anki 的设定上，
- `新卡片抽取顺序`：选择`按牌组顺序，再随机排列笔记`，这是卡组作者推荐的设定，因为作者说有特意调整过卡组顺序。
- `新卡片`-`初学间隔`: 设定成`6s 1m 10m`，对比默认的设定增加了`6s`这一档。`6s`意味着在最初的阶段每隔1-2张卡片之后又回到同一张不认识卡片，通过频繁的暴露可以在不用努力集中注意力的情况下也能强迫大脑记住。

同时调整了作者的卡片正面，主要是添加了假名的打字框和关闭了卡片正面的例句
```diff
...
      <span class="VocabPitch"></span>
    </h1>
    <div class="VocabAudio"></div>
  </header>
+ <div class="KanaInput">
+   {{type:VocabFurigana}}
+ </div>

  <ul class="SentenceList">
    {{#SentKanji1}}
    <li class="Sentence">
      <h3 class="SentKanji LabelIndent" lang="ja">
...
        win: 'goldendict',  // 在 Windows 使用 GoldenDict-ng 词典
        other: 'weblio',    // 在其他平台使用 Weblio 国語辞典
      },
      display: 'default',   // 正面单词显示: 'default' 显示汉字和注音假名（如有） | 'kana' 只显示假名 | 'kanji' 只显示汉字
-     frontExamples: 'all', // 正面例句区显示：'none' 无 | 'examples' 仅例句 | 'all' 例句、关联词和反义词
+     frontExamples: 'none', // 正面例句区显示：'none' 无 | 'examples' 仅例句 | 'all' 例句、关联词和反义词
      playback: 'force',    // 背面播放设置: 'default' 跟随牌组的系统设置 | 'force' 强制只播放单词音频
      autoCopy: {           // 背面自动复制: true 开启 | false 关闭
        ipad: true,
...
```
并在样式中添加
```
.KanaInput {
  width: 100%;
  padding: 10px 8px 14px;
  text-align: center;

  border-left: 1px solid var(--border);
  border-right: 1px solid var(--border);
}

.KanaInput #typeans {
  display: block;
  width: 12em;
  max-width: 80%;
  margin: 0 auto;
  text-align: center;
  font-size: var(--text-xl);
}
```
添加打字框是为了可以确保自己记住了而不是感觉自己记住了。关闭了卡片正面的例句是为了防止通过例句记住意思而没有通过单词记住意思。

## 不推荐的内容

- 多邻国：曾经学过几个月的多邻国，虽然每天只做几个单元压力很小，但是学了很久之后依然什么都不记得，是对时间极大的浪费。
- 新标准日语的单词表：刚开始学习日语的时候使用新标日的单词表背单词，但是里面混杂了人名地名等，背起来很痛苦，让我一度放弃了学日语。
